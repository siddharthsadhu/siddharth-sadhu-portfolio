## 🚀 Local Development Setup

Clone the repository and spin up the development environment in seconds:

```bash
# 1. Clone the repository
git clone https://github.com/siddharthsadhu/siddharth-sadhu-portfolio.git

# 2. Navigate to project root
cd siddharth-sadhu-portfolio

# 3. Install dependencies
npm install

# 4. Start local Vite development server
npm run dev
```

The application will be live at: `http://localhost:3000` (or `http://localhost:5173`).

---

## 🏗️ Production Build

To generate an optimized production bundle:

```bash
npm run build
```

The compiled output will be generated in the `dist/` directory ready for deployment on Vercel, Netlify, or GitHub Pages.
